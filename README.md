# Monochrome Muse — Nuxt 3 Photography Portfolio

A minimalist black-and-white photography portfolio inspired by TonYamanoStudio.com. Built with Nuxt 3 and Tailwind CSS, featuring smooth scrolling, responsive lightbox galleries, and accessible navigation.

## Getting started

```bash
pnpm install
pnpm dev
```

Or with npm:

```bash
npm install
npm run dev
```

The application will be available at `http://localhost:3000`.

## Features

- Sticky, accessible navigation with smooth scrolling to sections
- Hero section highlighting the studio ethos
- Curated category galleries (Women, Editorial, Fine Art, Commercial) backed by sample data
- Responsive image grids with keyboard-dismissable lightbox modal
- About section with services and client highlights
- Tailwind CSS styling with custom monochrome theme accents
- Basic SEO metadata and web font loading via Nuxt app head configuration
